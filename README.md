# 이차함수 땅따먹기

3~4명의 플레이어가 초대 코드로 참가해 이차함수 그래프가 스치는 격자 칸을 차지하는 실시간 온라인 게임입니다.

## 실행 방법

Python 3.10 이상이 필요합니다.

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

브라우저에서 `http://localhost:5000`을 엽니다. 같은 컴퓨터에서 시험하려면 시크릿 창을 포함해 브라우저 창 3개를 열어 각각 다른 닉네임으로 접속하면 됩니다.

다른 기기에서 접속할 때는 모든 기기를 같은 Wi-Fi에 연결한 뒤, 서버를 실행한 컴퓨터의 내부 IP를 사용합니다. 예: `http://192.168.0.10:5000`

## 기본 규칙

- 게임 인원: 3~4명
- 보드: x, y축 각각 -10부터 10까지인 20×20 격자
- 진행: 플레이어당 5턴
- 시작 순서: 각 플레이어가 1~100의 중복 없는 숫자를 뽑고, 큰 숫자 순으로 진행
- 순서가 정해진 뒤 각 플레이어가 함수·x축·y축 카드 더미를 한 번씩 눌러 종류별 카드 5장 묶음을 비공개로 뽑음
- 함수 카드 종류: `±4x²`, `±3x²`, `±2x²`, `±x²`, `±½x²`, `±⅓x²`, `±¼x²`
- 이동 카드 종류: x축·y축 각각 -8부터 +8
- 매 턴 세 종류에서 원하는 카드 한 장씩을 선택해 배치하며, 사용한 카드는 사라짐
- 그래프가 경계를 포함해 스치는 모든 칸을 점유
- 이미 점유된 칸은 가장 나중에 그래프를 그린 플레이어가 빼앗음
- 보드에는 보이지 않는 폭탄 4개가 있으며, 그래프가 폭탄 칸을 통과하면 주변 5×5칸의 모든 점유지가 삭제됨
- 마지막에 가장 많은 칸을 소유한 플레이어가 우승

게임 시작 전 방장이 **순서 정하기 시작**을 누르면 참가가 마감됩니다. 이후 모든 플레이어가 각자 **순서 숫자 뽑기**를 한 번씩 누르고, 숫자가 큰 순서대로 정렬되면 방장이 게임을 시작합니다.

## 1인 테스트 모드

첫 화면에서 닉네임을 입력하고 초대 코드 칸에 `TEST01`을 입력한 뒤 **참가**를 누르면 됩니다. 다른 플레이어 대기와 순서 정하기를 건너뛰고 1인용 카드 뽑기 단계로 바로 들어갑니다. 함수·x축·y축 카드 더미를 한 번씩 눌러 세 묶음을 모두 개봉하면 5턴짜리 테스트 게임이 자동으로 시작됩니다. 폭탄, 카드 선택, 그래프 점유, 애니메이션과 결과 화면은 일반 게임과 동일하게 작동합니다.

## 온라인 공개 시 참고

이 프로젝트는 서버 메모리에 게임 방을 저장합니다. 한 개의 Python 프로세스로 실행하는 소규모 수업·시연용에 적합합니다. 여러 서버 프로세스를 사용하는 정식 서비스로 확장하려면 Redis를 연결해 방 상태와 Socket.IO 메시지를 공유해야 합니다.
